# Tumble Wash Laundromat underwriting (1147 Summit Ave, Jersey City)

- `Tumble_Wash_Underwriting_Model.xlsx`: recast P&L, 17-year projection, federal/NJ depreciation, after-tax cash flow under four ownership structures, valuation and comps. Inputs sheet drives everything.
- `build_model.py` rebuilds the workbook; `snapshot.py <path-to-recalc.py>` reruns the scenario table on the Summary sheet (needs LibreOffice).
- `research/`: comparable sales and listings, tax rules (federal OBBBA, NJ, Jersey City), payroll and operating cost benchmarks, with sources.
- `listing/`: BizBuySell listing #2564518 PDF and extracted text.
